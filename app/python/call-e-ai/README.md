# CALL-E AI — Local Phone-Call Workflow Demo

CALL-E AI is a small Python demonstration of a phone-call agent workflow. It shows how a user can provide a phone number, describe a call purpose, confirm permission, and receive a simulated conversation.

This is a local demonstration, not a production calling service. It does not connect to a telephone network, place real calls, use an AI model, or require API credentials.

## Requirements

- Python 3.9 or newer
- No external Python packages
- No API keys or paid services

## Run locally

Open a terminal in this folder and run:

```bash
python demo.py
