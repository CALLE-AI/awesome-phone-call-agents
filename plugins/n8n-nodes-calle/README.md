# @call-e/n8n-nodes-calle

The CALL-E n8n community node is maintained in its standalone repository:

- [Source code, issues, releases, and contribution guidance](https://github.com/CALLE-AI/n8n-nodes-calle)
- [Published npm package](https://www.npmjs.com/package/@call-e/n8n-nodes-calle)
- [CALL-E Developer Docs](https://docs.heycall-e.com/)

This directory is intentionally documentation-only. Package source, tests, CI, and publishing no longer live in `awesome-phone-call-agents`.

The node can create real outbound calls. Follow the setup and safety guidance in the standalone repository, use only explicitly authorized E.164 destinations, keep credentials out of logs, and use stable idempotency keys to prevent duplicate calls.
