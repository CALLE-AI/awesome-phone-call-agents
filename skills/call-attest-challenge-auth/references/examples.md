# Examples: call-attest-challenge-auth

All outputs below are real, generated by running the commands. Example 1
uses a throwaway secret ("example-secret", via environment variable only)
and a pinned nonce (4f2a91) so the craft output is reproducible. In real
use the secret is your pre-shared value and the nonce is random.

## Example 1: crafting a challenge

Command (secret via environment variable only):

    ATTEST_EXAMPLE_SECRET=example-secret python3 scripts/attest_auth.py craft --scenario attestation-call --secret-env ATTEST_EXAMPLE_SECRET --nonce 4f2a91

Output:

