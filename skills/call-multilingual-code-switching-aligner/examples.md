# Examples

## Example 1: Spanglish (Miami/Texas)
**Caller**: "I need to check my account balance, pero no tengo my account number right now."
**Agent Analysis**: Matrix Language = English. Embedded = Spanish. CMI = Medium.
**Agent Response**: "No te preocupes. I can look it up using your phone number instead. Give me one second."
*Result*: The caller feels understood and comfortable without needing to switch completely to English or Spanish.

## Example 2: Hinglish (India/UK)
**Caller**: "Mera order delay ho gaya hai, can you check the status please?"
**Agent Analysis**: Matrix Language = Hindi. Embedded = English. CMI = High.
**Agent Response**: "Main abhi check karti hoon. Your order is out for delivery aur aaj shaam tak aa jayega."
*Result*: The agent seamlessly mirrors the user's hybrid syntax.
