# Examples and local demo

Use the host agent with `SKILL.md` and the contract on
`../examples/example-input.json`; save its actual JSON output to a local file.
The bundled `example-output.json` is an illustrative answer, not an inference engine.

From the repository root, Python 3.9+ (standard library only):

```bash
# Replay a labeled fixture and preview its effects. No inference, calls, or writes.
python3 skills/contact-preference-guard/demo/dry_run.py --case ongoing-window
python3 skills/contact-preference-guard/demo/dry_run.py --case today-only
python3 skills/contact-preference-guard/demo/dry_run.py --case order-only
python3 skills/contact-preference-guard/demo/dry_run.py --case complaint

# Preview a fresh proposal generated by the host agent.
python3 skills/contact-preference-guard/demo/dry_run.py \
  --input skills/contact-preference-guard/examples/example-input.json \
  --proposal /tmp/preference-proposal.json

# Ask for an explicit approve/reject after showing the full before/after preview.
python3 skills/contact-preference-guard/demo/dry_run.py --case today-only --confirm
```

The temporary case retains its time bound in a scoped record. The order case retains
its task identity. Neither changes `global_do_not_call`. The complaint needs semantic
clarification and offers no write path. An explicit organization-wide ongoing DNC
proposal instead previews `global_do_not_call: false -> true` and displays OPERATOR
APPROVAL REQUIRED. It does not ask the recipient to clarify an already explicit request.
Use `--input` and `--proposal` for this path; the four existing fixtures are unchanged.
Every mock write still needs `--confirm` and an explicit `approve`. Rejecting leaves
the file byte-for-byte unchanged.

Testing is separate from normal skill use. `../tests/golden-test-cases.json` contains
35 development cases. Do not provide expectations to the interpreting agent. Evaluate
newly generated outputs using `../scripts/validate.py`, as described in the contribution
README at `docs/contact-preference-guard/README.md` in the source repository.
