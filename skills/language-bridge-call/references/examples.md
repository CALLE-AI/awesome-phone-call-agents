# Examples

## Safe

- A property manager asks for a Saturday access window for a plumber; the tenant answers in their own language, and the manager accepts the chosen window on the callback.
- A workshop owner relays "bring the van's registration papers tomorrow" to a driver who prefers another language, and gets a yes/no plus a one-sentence confirmation.
- A coordinator previews both goal scripts (masked numbers) for a review, or replays the bundled fixture in a demo video, without dialing.
- A clinic front desk relays a non-medical logistics request (which documents to bring, what time to arrive) that staff already wrote in plain language.

## Unsafe

- Using the skill as a live interpreter for a doctor-patient or lawyer-client conversation.
- Relaying a payment demand, a lease amendment, an insurance settlement, or a deadline from a government agency.
- Calling a tenant whose number was shared by a third party rather than taken from the requester's own records.
- Retrying after voicemail, or placing a third "follow-up" call that the request never authorized.
- Letting the agent soften, expand, or translate the request text beyond the two scripted goals.
- Recording a demo with a real phone number visible in the request JSON or the terminal.
- Treating "agreed" as a signed commitment and skipping the human review of the structured result.
