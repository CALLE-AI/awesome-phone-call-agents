# Safety

- Use one strict E.164 number belonging to an authorized contact who consented to operational calls.
- Obtain approval for the exact masked preview immediately before the live call.
- Identify the caller as an AI calling assistant and ask permission to continue.
- Disclose only the non-secret case reference after recipient and permission checks.
- Request one specific replacement photo through a previously approved secure upload route.
- Never ask for an address, account detail, password, verification code, payment, legal position, medical information, claim decision, or new upload destination.
- One accepted provider run ends the calling phase. Timeouts, voicemail, refusal, ambiguity, and failure do not authorize a retry.
- Create no recurring schedule. The host owns any later re-evaluation after it independently observes a new file.
- Keep claim filing, refunds, payments, and every other consequential action under human control.
- Use provider cancellation if it remains available before connection. Once a call starts, cancellation is not guaranteed.
