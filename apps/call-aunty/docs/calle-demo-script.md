# CALL-E demo script (~3 minutes)

1. **Problem (20s):** A CHW sees a woman who needs follow-up after check-in. Closing the loop by phone is slow and easy to lose offline.
2. **Open record (20s):** Show Bangla-first woman record and due follow-up.
3. **Prepare (40s):** Tap **Start phone follow-up**. Show purpose, US demo recipient masking, English call language, dry-run badge, and side effects. Emphasize: UI Bangla ≠ call language.
4. **Confirm (40s):** Confirm dry-run. Show status → `dry_run_completed`.
5. **Map result (30s):** Show follow-up outcome / next action saved locally and queued for sync.
6. **Safety close (30s):** Mention consent, urgent deny, kill switch, no client API key, no auto-dial from sync.

Optional live coda: one authorized supported-region call with kill switch ready.
