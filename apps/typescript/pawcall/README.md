# PawCall

PawCall is an AI-powered animal emergency rescue coordination platform. When someone finds an injured animal, PawCall helps identify nearby responders and uses an AI voice agent to contact them and confirm whether they can help.

The prototype currently simulates the responder network using test phone numbers.

## How to Run

1. Install dependencies:
   `npm install`

2. Start the development server:
   `npm run dev`

3. Open:
   `http://localhost:3000`

## Features

- AI-powered animal emergency rescue coordination
- SOS emergency flow
- Responder discovery simulation
- AI voice calls to responders
- YES / NO / NOT CONFIRMED response handling
- Real-time dashboard status updates
- Test Mode for simulating multiple responders
- Manual next-responder calling
- English and Hindi voice interaction support

## Tech Stack

- React
- TypeScript
- Vite
- Node.js
- CALL-E voice agent
