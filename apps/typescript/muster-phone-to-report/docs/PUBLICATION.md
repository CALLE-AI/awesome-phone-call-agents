# Sanitized publication boundary

This app is a self-contained contribution. It does not import the private
development repository's Git history or require access to that repository.

Included: application source, synthetic tests and fixtures, dependency lockfiles,
architecture and API contracts, public demo instructions, CI, and reviewed brand
images. The current live-demo greeting and persistent-receiver fixes are included.

Excluded: internal Memory Bank task records, local project planning records,
previous Git objects and refs, runtime secret files, database activation files,
provider accounts and real phone numbers, private tunnel addresses, recordings,
protected transcripts, screenshots of private consoles, and logs.

Documentation tests use public architecture and authored behavioral contracts,
not historical provider-call records. Runtime safety assertions remain in place.
Full phone literals must use the reserved North American fictional subscriber
range 555-0100 through 555-0199. Fixtures must never be used for actual calls.
The publication-safety regression checks these boundaries without exposing values.

Before any public visibility change or upstream contribution:

1. Verify the exact files and complete new Git history with a secret scan and
   privately compare against configured live secret/phone/endpoint values.
2. Review image contents and metadata, README links, example configuration,
   licensing, and the final contribution diff.
3. Run the reproducible build, unit/integration suites, and browser checks.
4. Do not expose live-call controls, private source links, provider-call records,
   or private audit reports as substitutes for a credential-free demo. Check the
   complete contribution history, not only the latest file tree.
