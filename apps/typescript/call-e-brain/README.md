# 🧠 call-e-brain

**Voice Agent Command Center** – built with CALL-E.

call-e-brain is a web application that lets you create, save, and execute phone call plans powered by AI voice agents. It manages call history with full transcripts and summaries, making it easy to automate customer outreach, follow-ups, and surveys.

---

## ✨ Features

- 📋 **Create Plans** – Save phone numbers and scripts for repeated use.
- ✏️ **Edit Plans** – Update any saved plan inline.
- 📞 **One‑Click Calls** – Execute a plan with real CALL-E voice agents.
- 📜 **Call History** – View status, summary, and full transcript of every call.
- 🗑️ **Clear History** – Reset call logs with one click.
- 🔒 **Image & Text Protection** – Prevents copying of images and text outside input fields.
- 🌙 **Cyberpunk Theme** – Modern dark UI with neon accents.

---

## 🛠️ Tech Stack

- **Backend:** Node.js + Express
- **Database:** SQLite
- **Voice API:** CALL-E SDK (`@call-e/calle`)
- **Frontend:** Vanilla JS + CSS (cyberpunk theme)
- **Language:** English (interface and code)
