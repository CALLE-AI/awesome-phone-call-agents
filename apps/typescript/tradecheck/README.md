# TradeCheck

[![Next.js](https://img.shields.io/badge/Next.js-15-black)](https://nextjs.org/)
[![AI SDK](https://img.shields.io/badge/Vercel_AI_SDK-latest-black)](https://sdk.vercel.ai/)

**TradeCheck** is an experimental supplier-check demo combining public registry lookups with synthetic CALL-E-style call previews. The chat route cannot place real calls. Results are advisory, not proof of supplier identity, legitimacy, creditworthiness, or agreed terms.

China results are generated locally and are always synthetic; no CNBizAPI request is made. Other registry paths may use documented fallback data: inspect their source labels rather than treating every displayed result as a live registry match. Simulated conversations are generated by Gemini, not obtained from a supplier or CALL-E. Do not make payments or other consequential decisions from these demo results.

## Features

- **Conversational AI Copilot:** Natural language interface to gather trade deal requirements intuitively.
- **Documentary Checks (Government Registries):**
  - 🇮🇳 **India:** GSTIN verification via sandbox and live APIs.
  - 🇳🇬 **Nigeria:** CAC (Corporate Affairs Commission) registry lookup.
  - 🇬🇧 **UK:** Companies House direct API integration.
  - 🇨🇳 **China:** Local synthetic registry-shaped data only; no CNBizAPI integration.
  - 🇺🇸 **United States:** EIN/State-level entity verification.
- **Simulated Voice Verification:** Illustrates a [CALL-E](https://heycall-e.com)-style workflow with Gemini-generated synthetic conversations. No supplier is contacted; all call outcomes and confidence values are advisory demo data.

## Local Development

### Prerequisites

The chat requires a Gemini key; optional registry paths use the corresponding read-only API credentials:
- `GEMINI_API_KEY` (Google Gemini)
- `COMPANIES_HOUSE_API_KEY` (UK Companies House)
- `RAPIDAPI_KEY` & `APIFY_API_KEY` (For Nigerian CAC checks)
- `SANDBOX_API_KEY` & `SANDBOX_AUTH_TOKEN` (GSTIN API for India)

No CALL-E or CNBizAPI key is needed by the chat demo. The unused live-client source is not connected to any route and is not a supported live workflow.

### Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Favour-chuks/TradeCheck.git
   cd TradeCheck
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create an environment file and fill in your keys:
   ```bash
   cp .env.example .env.local
   ```
   *Edit `.env.local` with your actual API credentials.*

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open the app:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

## Supported Verification Paths

1. **India (Sandboxapi):** Requires GSTIN number or Company Name and phone number.
2. **Nigeria (CAC):** Requires RC Number or Company Name, and phone number.
3. **United Kingdom (Companies House):** Requires Company Number or Name, and phone number.
4. **China (synthetic preview):** Accepts a company name or USCC to generate example data, not a registry match.
5. **United States (EIN/State Registry):** Requires Company Name or EIN, and phone number.
