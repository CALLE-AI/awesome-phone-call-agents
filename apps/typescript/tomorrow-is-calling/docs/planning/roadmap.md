# Roadmap

## Phase 1 — Foundation

- Initialize React and TypeScript
- Organize hackathon documentation and task tracking
- Update README
- Add the reusable loader
- Create the mobile-first application shell

## Phase 2 — CALL-E proof of concept

- Register for, install, and configure CALL-E
- Review the official integration guide and choose SDK, API, MCP, CLI, or SKILL
- Create a secure backend
- Make one test call to the developer's own phone
- Confirm that the agent can speak, listen, adapt, and return a result

## Phase 3 — Practical scenario

- Select one real use case and define the user and phone-work problem
- Write the future-agent scenario and structured output fields
- Build one short adaptive conversation
- Test successful, unsuccessful, and unclear responses

## Phase 4 — Product experience

- Add phone-number input, clear consent, validation, and error states
- Create incoming-transmission and speakerphone-style status screens
- Add a post-call readiness or risk report
- Adapt the existing futuristic loader

## Phase 5 — Reliability and feedback

- Test on mobile and desktop
- Add failure and no-answer handling
- Track CALL-E bugs and limitations
- Record useful platform feedback
- Protect credentials and personal data
- Test the deployed application

## Phase 6 — Submission

- Deploy the functional application
- Open the required public pull request
- Record a public three-minute demo
- Add the pull-request URL to Devpost
- Add the CALL-E account email and optional functional demo URL
- Finalize README and submission materials
