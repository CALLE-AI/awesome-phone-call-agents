# Submission

## Checklist

- Open a pull request to the Awesome Phone Call Agents repository.
- Submit to the correct contribution area.
- Provide the pull-request URL on Devpost.
- Include a public demonstration video of approximately three minutes.
- Upload the video to YouTube or Vimeo.
- Provide the email address associated with the CALL-E account.
- Optionally provide a functional deployed application URL.
- Confirm that no API keys or personal phone numbers are exposed.

## Prize categories

- Most Practical Use Case — $4,000
- Most Innovative Use Case — $3,000
- Honorable Mention — $1,000 each for two winners
- Most Valuable Feedback — $200 each for five winners
