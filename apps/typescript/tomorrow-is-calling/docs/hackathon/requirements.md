# Requirements

## What to build

Build and deploy a functional application that uses CALL-E's SDK, API, MCP, CLI, or SKILL to create an impactful business or project use case.

## Runtime requirement

CALL-E must be imported and actually called at runtime. The final project must not rely only on mock data, fake phone screens, or documentation references.

## Account setup

- Install CALL-E
- Sign in
- Receive 20 free calls
- Connect the application through MCP, SDK, API, CLI, or SKILL

## Public contribution requirement

Open a pull request to `https://github.com/CALLE-AI/awesome-phone-call-agents`, following its README and contributing to the appropriate area, such as Agent Skills, Workflow Plugins, Applications, or Demonstrations.

## Important repository distinction

- CALL-E Integrations is for platform setup and integration guidance.
- Awesome Phone Call Agents is where the final contribution is submitted.
