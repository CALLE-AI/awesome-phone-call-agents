# Hackathon Brief

## Event

CALL-E — Your Code Is Calling

## Details

- Deadline: September 14, 2026 at 10:45 AM CDT
- Format: Online and public
- Prize pool: $10,000
- Account benefit: 20 free calls after account setup

## Challenge

Build and deploy a functional application that solves an impactful business or project use case and uses CALL-E through its SDK, API, MCP, CLI, or SKILL.

CALL-E agents can place real calls, converse naturally, adapt during a call, and return structured results for an application to use.
