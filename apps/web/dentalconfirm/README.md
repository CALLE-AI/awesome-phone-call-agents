# DentalConfirm

DentalConfirm is a web application that uses CALL-E AI phone agents to automate dental appointment confirmations.

## Problem

Dental practices spend significant staff time calling patients to confirm appointments. Missed appointments also create avoidable gaps in schedules.

## Solution

DentalConfirm provides a simple dashboard where staff can manage upcoming appointments and start an automated confirmation workflow using CALL-E.

The workflow can handle outcomes such as:

- confirmed
- reschedule
- cancelled
- no_answer

## Features

- Dental patient appointment management
- Personalized appointment confirmation workflow
- CALL-E phone-agent integration
- Call status and outcome tracking
- Simple web dashboard
- Designed to reduce administrative work and appointment no-shows

## Technology

- Node.js
- Express
- HTML / CSS / JavaScript
- CALL-E SDK
