# Examples

Everything here is fictional. The phone number is in the NANP `555-0100`-`555-0199`
block reserved for fiction, and the email uses the reserved `example.com` domain.

- `business.json` - the business profile and its qualification questions.
- `form_submission.json` - one web form submission, including the lead's
  `consent_to_call` checkbox.
- `fictional_completed_call.json` - a terminal CALL-E call task shaped like a
  `GET /v1/calls/{id}` response. It was written by hand for the offline replay path;
  it is not a recording of a real call.
