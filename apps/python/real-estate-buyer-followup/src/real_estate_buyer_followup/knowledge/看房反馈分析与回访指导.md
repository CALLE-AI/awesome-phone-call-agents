# 看房反馈分析与回访指导

经纪人维护的业务经验，用于规划沟通策略；不是客户已经表达的事实，也不是政策法规。

## [kb_guidance_price] 客户认为某套房源价格偏高
- published: 2026-11-02
- effective: 2026-11-02
- reviewed: 2026-11-02
- status: broker_guidance
- source: broker://knowledge/viewing-followup

场景：客户认为某套房源价格偏高

业务指导：
- 先确认客户是否认可房源其他方面。
- 区分「房源性价比不满意」和「预算绝对无法提高」。
- 如果客户表示价格可以谈，记录其条件，不自行承诺议价结果。
- 如果客户明确拒绝超预算房源，后续推荐应遵守预算约束。

场景：客户表示地铁远一点也可以

业务指导：
- 这是偏好可能放宽，不等于完全不重视交通。
- 应结合客户实际看房反馈，确认可接受的通勤代价。
- 未确认具体距离时，不得直接覆盖原来的精确数值。
