# 看房后回访：案例与时间线

本案例固定发生在2026年11月2日，使用虚构张女士与虚构房源。目的是展示Agent如何基于通话前资料规划，并从回访中新获知反馈和需求变化。没有实时房价或政策查询，也没有真实电话。

| 时间 | 已知信息 | 不能提前认定 |
| --- | --- | --- |
| 10月12日，首次需求 | 浦东三房，预算约500万，偏好地铁步行10分钟内 | 愿意提高预算或接受更远地铁 |
| 10月20日，补充沟通 | 客厅空间也重要，想看实际房子再比较 | 客厅已经优先于交通、已经放宽地铁距离 |
| 10月30日，完成带看 | A浦东花园：480万、客厅18㎡、地铁约8分钟；B滨江公馆：530万、客厅30㎡、地铁约18分钟 | A一定不满意、B一定喜欢、看了B就代表接受超预算 |
| 11月2日，本次回访前 | 两套已看，尚无实际反馈；Agent可以识别房源间的价格、空间、交通差异 | 确认的偏好排序或新的通勤上限 |
| 本次回访中，普通回放 | A位置不错但客厅小；B客厅满意但超预算；客户明确表示空间更重要、能接受地铁远一点，预算仍最多500万 | 新的精确通勤分钟数、预算增加或明确购买承诺 |
| 回访后 | 生成分房源反馈与偏好变化建议，保留转写依据；当前Demo不真正写CRM | 已完成CRM更新、已匹配新房源、已安排复看 |

B用于呈现空间、交通和价格的取舍，不把带看行为解释成预算松动。经纪人可在获知客户真实反馈后调整推荐；Agent不负责房源匹配。

## 通话前的三项沟通方向

1. 两套房源的独立反馈：分别了解满意点、不满意点、主要顾虑和继续考虑意愿。
2. 当前购房需求与取舍：结合真实体验了解空间、交通、预算的优先级，只在相关时深入预算弹性。
3. 后续跟进意愿：了解继续看房、复看、经纪人联系或暂缓联系的方向。

规划页与CALL-E Task不列逐题问句，不列房价、地铁资料等待核实清单。事实摘要由冻结的CRM历史按时间整理；模型负责形成沟通方向与条件策略。知识库中“客户表示地铁远一点也可以”是未来可能回答时的业务指导，不能转成客户的既有历史。

## 其他回放是独立分支

高意向、预算含糊、明确新预算、指代不清、拒绝联系、无转写及无人接听是同一通话前背景下的不同虚构结果，不是普通回访之后又连续发生的事件。高意向分支可提出有条件复看或议价；普通分支仅确认继续看合适房源，不应都判成高意向。
