\# Discharge Guardian



Post-discharge patient follow-up automation system. Calls high-risk patients within 48 hours of hospital discharge, detects care gaps (missed medications, worsening symptoms, unbooked follow-ups), triggers escalation for high-risk cases, and surfaces structured results to a clinical dashboard. Runs fully offline in mock mode by default — the entire pipeline (trigger → simulated call → persistence → dashboard) is runnable with zero external dependencies or API keys.



\*\*Stack:\*\* FastAPI, async SQLAlchemy, SQLite, Next.js dashboard, Docker Compose.
